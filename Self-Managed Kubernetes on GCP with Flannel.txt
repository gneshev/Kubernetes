
Student Exercise: Installing a 2-Node Kubernetes Cluster on GCP (Default VPC & Flannel)
Cluster Overview
Master Node: k8s-master

Worker Node: k8s-worker

CNI Network: Flannel (10.244.0.0/16)



Phase 1: Create the Virtual Machines in GCP Web Console


1. Open the GCP Console and navigate to Compute Engine > VM instances.

2. Click Create Instance.

3. Create the Control Plane VM with these settings:

Name: k8s-control-plane

Region / Zone: us-central1 / us-central1-a (or any zone near you)

Machine configuration: e2-medium (2 vCPU, 4 GB memory)

Boot disk: Click Change, select Ubuntu, choose Ubuntu 24.04 LTS, and set size to 20 GB.

Advanced options > Networking:

	Network: default

	IP forwarding: Check Enable IP forwarding (Crucial for Flannel!).

4. Click Create.

5. Repeat the exact same steps to create k8s-worker.




Step 2: Open Required Ports in GCP Firewall
1. Navigate to VPC network > Firewall in GCP Console and click Create Firewall Rule:

Rule Name: allow-k8s-internal

Network: default

Source IP ranges: 10.0.0.0/8, 10.244.0.0/16

Protocols and ports: Select Allow all.

2. Click Create.

Phase 2: Node Prerequisites & Installation

1.Disable Swap Space:
Execute on BOTH Terminal 1 (Master) and Terminal 2 (Worker).
Kubernetes requires swap memory to be completely disabled.

# Disable swap immediately
sudo swapoff -a

# Permanently disable swap across reboots
sudo sed -i '/ swap / s/^\(.*\)$/#\1/g' /etc/fstab


2.Configure Kernel Modules & Networking:
Execute on BOTH Terminal 1 and Terminal 2.
Enable overlay networking, bridge filter support, and IPv4 forwarding.


sudo bash -c '
cat <<EOF > /etc/modules-load.d/k8s.conf
overlay
br_netfilter
EOF
modprobe overlay
modprobe br_netfilter
cat <<EOF > /etc/sysctl.d/k8s.conf
net.bridge.bridge-nf-call-iptables  = 1
net.bridge.bridge-nf-call-ip6tables = 1
net.ipv4.ip_forward                 = 1
EOF
sysctl --system
'




3.Install containerd Container Runtime:
Execute on BOTH Terminal 1 and Terminal 2.
Install and configure containerd with SystemdCgroup enabled for Kubernetes systemd integration.


sudo bash -c 'apt-get update && apt-get install -y containerd && mkdir -p /etc/containerd && containerd config default > /etc/containerd/config.toml && sed -i "s/SystemdCgroup = false/SystemdCgroup = true/g" /etc/containerd/config.toml && systemctl restart containerd'



4.Install Kubeadm, Kubelet, and Kubectl:
Run on BOTH Terminal 1 and Terminal 2.

sudo bash -c 'apt-get update && apt-get install -y apt-transport-https ca-certificates curl gpg && mkdir -p -m 755 /etc/apt/keyrings && curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.30/deb/Release.key | gpg --dearmor --yes -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg && echo "deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.30/deb/ /" > /etc/apt/sources.list.d/kubernetes.list && apt-get update && apt-get install -y kubelet kubeadm kubectl && apt-mark hold kubelet kubeadm kubectl'



5.Initialize Kubernetes Control Plane:
Run ONLY on Terminal 1 (Control Plane).
Start the Kubernetes cluster on the control plane node.

# Initialize cluster with Flannel's expected pod network CIDR
sudo kubeadm init --pod-network-cidr=10.244.0.0/16


Once complete, set up standard user access to use kubectl:

mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config


Important: Look at the end of the command output in Terminal 1. Copy the full line starting with sudo kubeadm join .... You will need it in Step 6.



6.Install Flannel Network Plugin:
Run ONLY on Terminal 1 (Control Plane).
Flannel manages pod networking across the cluster.

kubectl apply -f https://github.com/flannel-io/flannel/releases/latest/download/kube-flannel.yml
